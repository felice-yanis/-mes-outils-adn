# 🧬 Suite d'outils Bio-informatique - Python

Projet personnel développé en Terminale STL Biotechnologie pour automatiser l'analyse de séquences ADN.

## 🚀 Les 3 outils
1. **analyse_adn.py** : Calcule longueur et %GC (avec nettoyage .upper()/.strip())
2. **compteur_bases.py** : Compte les occurrences A/T/C/G
3. **detecteur_anomalie.py** : Détecte les bases invalides (contrôle qualité labo)
4. **main.py** : Programme principal qui enchaîne les 3 analyses

## 🛠️ Compétences techniques
- Python (fonctions, boucles, conditions)
- Nettoyage de données biologiques
- Gestion d'erreurs / Contrôle qualité
- Git & GitHub
